# Texts and translations

Arcalo Mail shows every text in German and English, with the rules of Arcalo's `docs/i18n.md`. The automatic check
`ui/src/lib/translations.test.ts` (taken from Arcalo) enforces them.

## Where texts live

- **Interface:** `ui/src/locales/en.ts` (English, the source of the key type) and `ui/src/locales/de.ts`. Keys are
  grouped by area (`area.name`). Components call `t("area.name", { name })` from `useT()`.
- **Backend** (error messages, later notifications and menus): pairs in the Rust code, `tr!("Deutsch", "English")`
  for a fixed text and `trf!("„{name}“ fehlt", "“{name}” is missing", name = …)` for one with values
  (`crates/mail-core/src/i18n.rs`). Write them with literal strings; the check reads them from the source.
- **Glossary:** `ui/src/locales/glossary.json`, the preferred term per concept and the variants that must not
  appear.

## Adding a text

1. Add the key to `en.ts` and `de.ts` at the same place (the typecheck fails if one is missing).
2. Use the same `{placeholders}` in both languages. A text with a count is a plural:
   `{ one: "{n} Nachricht", other: "{n} Nachrichten" }`. Do not write `Nachricht(en)` or `message(s)`.
3. Name things with the glossary terms and keep the address form (below).
4. Run `npm --prefix ui test`. The translation check names each problem with its key.

## Address form

German texts say **du**, or stay impersonal: „Ordner wählen“, „Externe Inhalte laden“. Never „Sie“, „Ihr“,
„Ihnen“ for the reader. A „Sie“ that means „they“ is fine. English texts are plain and direct.

## Typography

German quotes „…“, English quotes “…”; … (one character) for an ellipsis, written right after the word in labels
(„Suchen…“); an en dash with spaces (–) between parts of a sentence; units with a space (10 MB).
